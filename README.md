# About the Project
 - Ethiopian Cultural Foods is a simple website built to showcase Ethiopia's traditional dishes such as Injera, Doro Wat, and     Shiro Wat, along with authentic ingredients, spices, and food traditions.

##Website Features
  - Introduction to traditional Ethiopian cuisine.
  - Information about Ethiopian spices and ingredients.
  - Descriptions of popular Ethiopian dishes.
  - Food images and descriptions.

##Technologies Used
 - HTML5 – Used to structure the website.
 - CSS3 – Used to style and design the website.

##How to Run the Project
1. Clone this repository:
  -  git clone https://github.com/YOUR-USERNAME/ethiopian-cultural-foods.git

2. Open the project folder.
  -  Open index.html in your web browser.
